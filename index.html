01 — 源起

效法蜜蜂，
把花園收成系統。

如果開源是一座大花園，BeeOps 就是那群把果實送達的蜜蜂。開放即力量。

地球上有一種昆蟲，日出而作、日落而息。牠替植物授粉，讓季節得以循環——蜜蜂。

人類用蒸汽把機器轉起來，用電力把城市點亮，用網路改寫人與人共事的方式。現在，AI 正在發動第四次工業革命。疫情把生意推上網，ChatGPT 則讓生成式 AI 在幾個月內成為企業不能不面對的能力。

03 — 蜂巢在忙什麼

四種平台，一種交付方式。

協助企業與機關導入、使用、管理開源軟體。規劃、建置、維運、升級，加上顧問級技術移轉與教育訓練。

01 / OS

開源作業系統

社群版或商用版 Linux。實體機、虛擬機或容器化，從系統規劃、建置、管理、監控到健檢。

  • Linux
  • 實體機
  • 虛擬機
  • 監控
  • 健檢
02 / CLOUD

雲地混合容器

以 Kubernetes 為核心的容器運算與管理。你的團隊先熟悉日常維運，專家帶你進入容器平台。

  • Kubernetes
  • 雲地混合
  • 維運
  • 升級
03 / KVM

虛擬主機平台

以 Proxmox VE 管理 KVM，以 Proxmox Backup Server 做備份與還原。包含 VMware 之外的開源選擇。

  • Proxmox VE
  • Backup Server
  • KVM
  • 還原
04 / GENAI

私有生成式 AI

文案、語音、影像、翻譯、自動化。開源 LLM 與 AI 套件評估、規劃、建置，資料留在自己的環境。

  • Private AI
  • Open LLM
  • RAG
  • 內網

04 — 解法

混合雲，拆開來看。

LINUX

作業系統與管理平台

協助導入開源 Linux，不管跑在實體機、虛擬機或容器。範圍含系統規劃、建置、管理、監控、健檢，以及顧問級的技術移轉與教育訓練。

  • 規劃
  • 建置
  • 管理
  • 監控
  • 健檢
  • 教育訓練

HIGH AVAILABILITY

讓該在線上的服務留在線上

以 Linux 為核心，結合 Pacemaker 與 Corosync，為企業高可用需求做整體規劃、建置、維護與教育訓練。適合不能停機的服務。

  • Pacemaker
  • Corosync
  • 叢集
  • 教育訓練

VIRTUALIZATION

Proxmox VE 與 Backup Server

企業級虛擬機管理平台的規劃、建置、維護與升級。Proxmox Backup Server 負責 KVM 的備份與回復，並提供顧問級技術移轉與教育訓練。當虛擬機要換一種管法，這是一條開源的路。

  • Proxmox VE
  • PBS
  • KVM
  • VMware 替代

CLOUD NATIVE

雲地開發與雲原生應用

為雲端原生應用準備開發平台：Java 或 Python，搭配 WildFly、Tomcat 等中介軟體，接上 MongoDB、MariaDB、Redis，組成可以交付的雲原生服務。也做客製化的雲地整合導入。

  • Java
  • Python
  • WildFly
  • Tomcat
  • MongoDB
  • MariaDB
  • Redis

CONTAINERS

安全的 Kubernetes 平台

以 Kubernetes 為核心，從規劃、建置、維護到升級。企業先掌握基本容器維運，由專家等級的技術支援帶進容器平台，把注意力放回要給客戶的服務。AI、ESG、Big Data、數據中台與 API，都可以是這座平台上的工作負載。

  • Kubernetes
  • 安全
  • 維運移轉
  • 應用上平台

PRIVATE AI

安全、私有的 GenAI 平台

生成式 AI 用來抬高流程與產能：文案、語音、影片、翻譯、自動機器人。我們協助導入私有 AI 平台，把開源 LLM 與 AI 套件從評估、規劃一路做到建置，不把第一步就交到別人的雲上。

  • Open Source LLM
  • 評估
  • 規劃
  • 建置
  • 教育訓練
